REST API — POST /api/predict

Send a JSON body with the same fields as the form. This endpoint doesn't render a page — it's meant to be called from code, curl, Postman, or another app, which is why the nav link opens this reference instead of navigating there directly.

Request

curl -X POST {{ request.url_root }}api/predict \
  -H "Content-Type: application/json" \
  -d '{
    "present_price": 6.5,
    "kms_driven": 45000,
    "fuel_type": 0,
    "seller_type": 0,
    "transmission": 0,
    "owner": 0,
    "car_age": 5
  }'

Response — 201 Created
